# Better Kumo on Android

Better Kumo isn't in Google Play. You install the APK from the release. The full guide, including building it
yourself, is [install.md §3](install.md#3-android-phone).

## Install

1. On the phone open the **[latest release](https://github.com/IgorKravtsov/better-kumo-app/releases/latest)** and
   download `Better-Kumo-Android-<version>.apk`.
2. Tap the file. Android asks to allow installs from your browser: allow it.
3. Google Play Protect may warn about an unknown developer: **More details → Install anyway**.

Updates install the same way over the old version; sign-in and data are kept.

## First launch

1. Allow **notifications**: chat alerts need them.
2. Sign in with **Sign in with browser** ([install.md §5](install.md#5-signing-in-on-a-phone)).
3. Settings → Apps → Better Kumo → Battery → **Unrestricted**, so alerts keep coming in the background. On Samsung,
   Xiaomi and similar phones see also dontkillmyapp.com.

## Pair it with the computer

On the computer open the Setup guide's phone step, or Settings → Phones. Point the camera app, or any QR scanner, at
one code: it opens Better Kumo and connects. The details are in [install.md §6.3](install.md#63-pair-the-phone).
